# Tic Tac Toe

This is a console tic tac toe game written in a big python file. It was originally created for an industrial robotics course to make a Dobot Magician robot arm play the game. This python file is an alternative console game version without the logics for the Dobot Magician.

## Start the game

To start the game, run:

```bash
python ./TikTakToe.py
```
